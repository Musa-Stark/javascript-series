WHAT IS AN API? - Application Programming Interface
==========================================

client (mobile) ---- req ----> server ----> data ----> mobile

Imagine you are sitting in a restaurant.

You don't go inside the kitchen.

You tell the waiter what you want.

The waiter goes to the kitchen.

Brings your food.

Restaurant

Customer (mobile/laptop)
↓

↓

↓

↓

WHAT IS JSON? ----> Java Script Object Notation
==========================================

Most APIs send data in JSON.

Example

{
    name: "musa"
}

{
    "name":"Ali",
    "age":20,
    "city":"Peshawar"
}

Explain

JSON looks almost like JavaScript Objects.

Difference

JSON keys are always inside quotes.

HTTPS ----> Hyper text transfer protocol Secured
HTML ----> Hyper text markup langauge

mobile ----> API(JSON) (MMA) ----> server

    const response = await fetch("API_URL");

    const data = await response.json();

}

getUsers();

Explain every line.

async

This function can wait.

await fetch()

Wait until server responds.

response.json()

Convert JSON into JavaScript Object.

data

Actual information.
